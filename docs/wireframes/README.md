As cinco primeiras telas incluem listagem, filtros e formulário reutilizado em cadastro, edição e visualização. A consulta bloqueia campos; a exclusão apresenta confirmação explícita. No celular, os formulários ficam em uma coluna e tabelas/menu permitem rolagem própria. O protótipo de consultas representa a tela que consome as sete rotas originais do `FiltrosController`.
